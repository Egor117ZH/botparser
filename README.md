# botparser

Тг-бот для мужского канала (стиль, парфюм, психология, физуха).
По команде собирает свежие посты из тг-каналов и статьи с сайтов, через нейронку (Polza AI) отбирает лучшее и присылает тебе в личку.
Под каждым постом есть кнопка **🔄 Уникализировать**: нейронка переписывает пост своими словами.

## Как работает

1. **Каналы** читаются из-под твоего аккаунта (Telethon), берутся посты за последние `HOURS_BACK` часов.
2. **Сайты** парсятся так: сначала ищется RSS, если его нет, то ссылки на статьи с главной. Текст статьи достаётся через trafilatura.
3. **Оценка** по совокупности факторов:
   - интерес по мнению нейронки: польза, новизна, цепляет ли (45%)
   - насколько в тему (30%)
   - реакция аудитории: просмотры относительно среднего по каналу, реакции, репосты, комменты (25%)
   - то, что не в тему (relevance < `MIN_RELEVANCE`), отсекается сразу
4. **Посты из каналов** присылаются как есть, с фото. **Из статей** нейронка сразу пишет короткий пост.
5. Что уже присылалось, повторно не придёт (хранится в `data/bot.db`).

## Запуск на Windows

1. Получи доступы:
   - **BOT_TOKEN**: в @BotFather → `/newbot`
   - **TG_API_ID / TG_API_HASH**: https://my.telegram.org → API development tools (название приложения любое)
   - **POLZA_API_KEY**: в личном кабинете polza.ai
2. Двойной клик по `run.bat`. В первый раз он создаст окружение, поставит библиотеки и откроет `.env`, туда впиши ключи.
3. Снова запусти `run.bat`. В консоли телега спросит **код подтверждения** (придёт в приложение телеги) и пароль 2FA, если он есть. Это нужно один раз, дальше сессия сохраняется в `data/`.
4. Если `ADMIN_ID` пустой, напиши боту что угодно, он ответит твоим id. Впиши его в `.env` и перезапусти.
5. Добавь источники в `channels.txt` / `sites.txt` или прямо в боте: `/addchannel @name`, `/addsite https://...`
6. Жми **🔎 Собрать посты**.

Вручную, без bat:
```
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python main.py
```

## Команды бота

| | |
|---|---|
| 🔎 Собрать посты / `/collect` | собрать и прислать лучшее |
| 📋 Источники / `/sources` | список каналов и сайтов |
| `/addchannel @name` | добавить канал |
| `/addsite url` | добавить сайт |
| `/reset` | забыть, что уже присылалось |

## Настройка

- Промпты (темы, стиль постов, уникализация) лежат в `bot/prompts.py`, их можно править под себя.
- Количество постов, пороги и окно по времени задаются в `.env`.
- Модель: `POLZA_MODEL`, список на https://polza.ai/models (формат `провайдер/модель`).

## Важно

- `.env` и папку `data/` (там сессия твоего аккаунта!) никому не отдавай и не заливай в git. Они уже в `.gitignore`.
- Лучше завести под userbot отдельный аккаунт, а не основной.
