# botparser

Тг-бот для мужского канала (стиль, парфюм, психология, физуха).
По команде собирает свежие посты из тг-каналов и статьи с сайтов, через нейронку (Polza AI) отбирает лучшее и присылает тебе в личку.
Под каждым постом есть кнопка **🔄 Уникализировать**: нейронка переписывает пост своими словами.

## Две рубрики

| Кнопка | Что собирает | Источники | Хэштег |
|---|---|---|---|
| 📰 Новости | свежие новости по мужским темам (стиль, парфюм, психология, форма) | `sources_news.txt` | `#Новости` (`NEWS_HASHTAG`) |
| 🧠 Мышление | истории, принципы, мужское мышление | `sources_stories.txt` | нет (`STORIES_HASHTAG`) |

**Источники удобнее всего править прямо в боте:** «📋 Источники» → выбираешь рубрику → «➕ Добавить» (можно кинуть сразу несколько ссылок, каждую с новой строки) или «🗑 Удалить».
Быстрые команды: `/addnews site.ru`, `/addstory site.ru`. Ещё можно руками в файлах: сайты и тг-каналы вперемешку, по одному на строку.

## Как работает

1. Бот собирает материалы из источников рубрики. Новости старше `NEWS_MAX_AGE_HOURS`, если у статьи есть дата, не берутся.
2. Нейронка оценивает каждый материал под рубрику: насколько подходит и насколько интересен. Для тг-постов ещё учитываются просмотры и реакции.
3. **Защита от повторов:**
   - один и тот же материал второй раз не придёт
   - если одна новость или история есть в нескольких источниках, нейронка оставит только одну
   - бот помнит, о чём уже писал (последние `HISTORY_SIZE` тем), и не повторит ту же новость или историю, даже с другого сайта и другими словами
   - один пост = одна новость или одна история
4. По каждому отобранному материалу нейронка пишет короткий пост. Под постом есть кнопка **🔄 Уникализировать**, она даёт другой вариант текста.

## Запуск на Windows

Нужен **Python 3.12** (подойдёт 3.10–3.14), 64-bit. На 3.15 и 32-битном питоне библиотеки не ставятся. `run.bat` сам найдёт подходящий питон, если их стоит несколько.

1. Получи доступы:
   - **BOT_TOKEN**: в @BotFather → `/newbot`
   - **TG_API_ID / TG_API_HASH / TG_PHONE**: *необязательно*, только для чтения тг-каналов. https://my.telegram.org → API development tools. Если оставить пустыми, бот работает только по сайтам
   - **POLZA_API_KEY**: в личном кабинете polza.ai
2. Двойной клик по `run.bat`. В первый раз он создаст окружение, поставит библиотеки и откроет `.env`, туда впиши ключи.
3. Снова запусти `run.bat`. В консоли телега спросит **код подтверждения** (придёт в приложение телеги) и пароль 2FA, если он есть. Это нужно один раз, дальше сессия сохраняется в `data/`.
4. Если `ADMIN_ID` пустой, напиши боту что угодно, он ответит твоим id. Впиши его в `.env` и перезапусти.
5. Добавь источники прямо в боте: «📋 Источники» → рубрика → «➕ Добавить»
6. Жми **📰 Новости** или **🧠 Мышление**.

Вручную, без bat:
```
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python main.py
```

## Прокси (РФ)

Если запуск падает с «не достучался до api.telegram.org» или «не подключился к серверам телеги», нужен прокси. Впиши в `.env`:

```
PROXY=socks5://логин:пароль@1.2.3.4:1080
```
или `http://...`. Этот прокси работает и для бота, и для чтения каналов.

- `MTPROXY=host:port:secret`: MTProto-прокси (из ссылок `t.me/proxy?...`). Работает только для чтения каналов, боту всё равно нужен `PROXY`. Секреты на `ee` не поддерживаются.
- `PROXY_FOR_SITES=1`: парсить сайты тоже через прокси (если зарубежные сайты не открываются).
- Polza AI российская, ей прокси не нужен.

## Команды бота

| | |
|---|---|
| 📰 Новости / `/news` | собрать новости |
| 🧠 Мышление / `/stories` | собрать истории и посты про мышление |
| 📋 Источники / `/sources` | посмотреть, добавить, удалить источники по рубрикам |
| `/addnews url или @канал` | добавить источник в новости |
| `/addstory url или @канал` | добавить источник в мышление |
| `/reset` | забыть, что уже присылалось, и историю тем |

## Настройка

- Промпты (темы, стиль постов, уникализация) лежат в `bot/prompts.py`, их можно править под себя.
- Количество постов, пороги и окно по времени задаются в `.env`.
- Модель: `POLZA_MODEL`, список на https://polza.ai/models (формат `провайдер/модель`).

## Важно

- `.env` и папку `data/` (там сессия твоего аккаунта!) никому не отдавай и не заливай в git. Они уже в `.gitignore`.
- Лучше завести под userbot отдельный аккаунт, а не основной.
